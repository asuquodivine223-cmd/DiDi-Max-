# Build DiDi Max

Open the project in Android Studio.

1. File > Open > select the DiDiMax folder.
2. Allow Gradle sync to complete.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. For Google Play, choose Build > Generate Signed Bundle / APK and create a release key.

Application ID: com.didimax.app
Version: 1.0.0
Min SDK: 24
Target SDK: 35
